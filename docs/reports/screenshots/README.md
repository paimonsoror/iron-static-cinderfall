# Screenshots of V5-B (presentation integration)

Every picture was made on the desktop with the real Mobile / Vulkan renderer (`renderer=mobile/vulkan`) and then OPENED and looked at (as contact sheets and at full size) before it was listed here. They are stored at half size (540 x 1171 for the phone's 1080 x 2342; 720 px wide for the wide window), 8-bit palette, optimised: 53 files, 5.4 MB. **52 pass, 1 issue** (the issue is listed below).

How they are made: the HUD pictures are `view_sandbox.tscn` with `--hud` (the real `CombatHud` over the puppet's real `SimWorld`; `--scenario=boss:<id>`, `event:<id>`, `chain<N>+<M>`, `mixed<N>+<M>` run the real boss and event systems), the screens are the `_sandbox` scenes, the overlays are `hud_sandbox.tscn --state=...`. `CINDERFALL_ARGS` carries the flags (capture.ps1 cannot forward them). The four new bosses need the boss data of `task/V4-N-bosses-data` (main's `data/enemies.json` holds the Siege Hulk only; V5-A merges it): those pictures were made in a throwaway worktree with that branch merged. Raw 1080 px captures are in `build/shots/` of that worktree and are not committed.
